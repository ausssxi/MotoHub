# バイクわらしべ長者 - NPC全セリフ集

## セリフの構造（ミミクリーマン準拠）

各NPCのセリフは以下の構成：
1. **待機セリフ** - エリアに入った時に見えるつぶやき（ヒント）
2. **話しかけ** - プレイヤーが話しかけた時の第一声
3. **正解セリフ** - 欲しいバイクを見せた時（交換成立）
4. **ハズレセリフ** - 間違ったバイクを見せた時（カテゴリ別に反応が変わる）
