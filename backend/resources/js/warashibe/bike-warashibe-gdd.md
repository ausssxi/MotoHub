# バイクわらしべ長者 - 交換ツリー設計書

## ゲーム概要
- スタート: スーパーカブ50
- ゴール: 隼（Hayabusa）を入手
- バイク総数: 18車種
- ライダーNPC: 14人
- カスタム（合成）: 5レシピ
- エリア: 5箇所
- プレイ時間目標: 30分〜1時間

---

## エリア構成

### 1. 街（スタート地点）
通勤・日常ユースのライダーが集まる。原付〜125ccクラス中心。
NPCの特徴: 燃費・取り回し・維持費を重視する人たち。

### 2. 郊外
ツーリング好きが集まるバイク用品店前の駐車場。125〜400ccクラス。
NPCの特徴: 積載性・長距離快適性・見た目を重視。

### 3. 峠
走りを楽しむライダーの聖地。250〜600ccクラスのスポーツ系。
NPCの特徴: パワー・ハンドリング・軽さを重視。

### 4. 海岸通り
クルーザー・アドベンチャー系が集まる海沿いの道。400〜1000cc。
NPCの特徴: 存在感・カスタム文化・ロングツーリングを重視。

### 5. サーキット（最終エリア）
レース志向のライダー。リッタークラス。
NPCの特徴: 最高速・馬力・レース実績を重視。

## 交換ツリーのポイント

### メインルート（最短）
カブ50 → PCX → CT125 → CRF250L → Ninja250 → YZF-R3
→ (合成)YZF-R3カスタム → Z900 → MT-09 → CBR600RR
→ (合成)CBR600RRレーサー → ZX-10R → (合成)ZX-10Rフルチューン → 隼
= 約12ステップ

### サブルート（GB350ルート）
CT125 → GB350 → CB400SF → MT-07 → (峠ルート合流)
※このルートでしか手に入らないバイクがあり、図鑑コンプに必要

### 合成の必要素材
1. 社外マフラー: 峠のパーツ屋（MT-07入手後に開放）
2. ツーリングパニアケース: 海岸通りのバイク用品店
3. レーシングカウル: サーキットのピット
4. ターボキット: Vストローム入手時の情報→隠しショップ

### エリア開放条件
- 街: 最初から
- 郊外: CT125入手後
- 峠: 250cc以上のバイク入手後
- 海岸通り: 400cc以上のバイク入手後
- サーキット: 600cc以上 or Z900入手後

## ハズレリアクション例（間違ったバイクを提示した時）

ミミクリーマンの面白さの核の一つ。NPCごとに個性的な反応。

### 通勤おじさんに大型バイクを見せた場合
「す、すごいバイクだけど...駐輪場に入らないよ...」

### 女子大生にオフロード車を見せた場合
「え、これで大学行くの...？泥はねとか無理なんだけど...」

### 峠の走り屋にアメリカンを見せた場合
「...ヘアピンでステップ擦るだろ、それ」

### 伝説のライダーにカブを見せた場合
「...面白いやつだな。だが、まだ早い」（特殊セリフ：全クリ後にカブで話しかけると隠しイベント）

## マルチエンディング

### ED1: ノーマルエンド
隼を入手してクリア。「あなたはドリームバイクを手に入れた！」

### ED2: グッドエンド
隼入手 + バイク図鑑80%以上。各ライダーの後日談が見られる。

### ED3: トゥルーエンド（100%コンプ）
全バイク図鑑コンプ + 全NPCのハズレリアクション回収。
隠しバイク「MotoHub Special」が図鑑に追加される。
→ MotoHubの車両ページへのリンク付き

## MotoHub実データ連動ポイント

1. **バイク図鑑の相場表示**: 各バイクの現在の中古相場をMotoHubから取得して表示
2. **地域別人気**: NPCの「欲しがる理由」にMotoHubの地域別人気データを反映
3. **売却日数**: 人気バイクほど交換が早い（演出として「即決だ！」vs「うーん...まぁいいか」）
4. **クリア後リンク**: 図鑑からMotoHubの各車両ページへ直接リンク
5. **ランキング連動**: MotoHubの売れ筋ランキングデータでNPCのセリフを動的に変更（将来実装）
