# バイク盗難統計データ（theft_stats.json）取得・整形手順

面①`/theft` ハブ・面②県別ページ盗難ブロックが読む静的データの**取得元・整形手順・スキーマ**。
年1回の差し替え（`config/theft.php` の `data_year` / `checked_at` も同時更新）を再現可能にするための記録。

---

## 1. 一次情報（これだけを使う。孫請け加工データ禁止）

- **警察庁『犯罪統計』第9表「街頭犯罪等 都道府県別 認知・検挙件数」**（e-Stat＝政府統計の総合窓口）
  - 統計: 警察庁 犯罪統計（`toukei=00130001` / `kikan=00130`）、データセット群 `tstat=000001103615`
  - e-Stat 検索: https://www.e-stat.go.jp/ →「犯罪統計」→ ファイル →「**第9表 街頭犯罪等 都道府県別**」
  - この第9表に、街頭犯罪の内訳として **「オートバイ盗」の認知件数・検挙件数が都道府県別**で載っている
    （街頭犯罪総数＝路上強盗・部品ねらい・車上ねらい・自動販売機ねらい・**オートバイ盗**・自転車盗 の合計）。
  - 形式: **Excel / CSV / PDF**（機械可読はExcel/CSV）。

> ⚠️ 使わない表（オートバイ盗×都道府県×年次にならない）：
> - 第2表「窃盗 手口別」＝オートバイ盗はあるが**全国のみ**（都道府県軸なし）
> - 第3表/第4表/第6表「都道府県別」＝**罪種が粗く**オートバイ盗単独ではない

### 年次カバレッジの注意
- e-Stat の第9表（街頭犯罪 都道府県別）の機械可読ファイルは概ね **2016年（平成28年）〜最新**。
- **各年の確定値＝その年の「1〜12月」累計ファイル**を使う（月次・途中累計ではなく年計）。
- 2006〜2015 の古い年を推移に含めたい場合は、警察庁『犯罪統計書』（年報PDF/Excel, npa.go.jp）から別途手作業抽出が必要。
  **初版は e-Stat で機械可読に取れる 2016〜最新でよい**（`years` 配列は可変。SVGは入っている年数に自動追従）。

## 2. ダウンロード手順（各年ぶん・認知/検挙の両方）

1. e-Stat で「警察庁 犯罪統計」→ 対象年の「**◯年1〜12月 犯罪統計**」→「**第9表 街頭犯罪等 都道府県別 認知件数・検挙件数**」を開く。
2. **Excel（またはCSV）でダウンロード**。認知件数表・検挙件数表が別シート/別ファイルの年もあるので**両方**取得。
3. 対象年（初版: 2016〜最新）ぶん繰り返す。
4. 各ファイルから、**47都道府県 × オートバイ盗の {認知件数, 検挙件数}** を抜き出す。
   - 都道府県は**公式フルネーム**（北海道／東京都／京都府／大阪府／◯◯県）で保持すること（後述の名寄せキー）。
   - 「全国」「警察庁」等の合計行は**除外**（47県のみ）。

## 3. 整形後スキーマ（`database/data/theft_stats.json`）★これが正本

```json
{
  "meta": {
    "source_label": "警察庁『犯罪統計』第9表 街頭犯罪等 都道府県別（e-Stat）",
    "source_url": "https://www.e-stat.go.jp/stat-search/files?tstat=000001103615",
    "crime": "オートバイ盗",
    "note": "各年の確定値（1〜12月累計）。認知=recognized, 検挙=cleared。"
  },
  "years": [2016, 2017, 2018, 2019, 2020, 2021, 2022, 2023, 2024, 2025],
  "prefectures": {
    "北海道": { "2016": { "recognized": 000, "cleared": 000 }, "2017": { "recognized": 000, "cleared": 000 } },
    "青森県": { "2016": { "recognized": 000, "cleared": 000 } }
  }
}
```

### スキーマ規約（アプリ側の前提）
- **`years`**：昇順の対象年（整数）。推移グラフ・最新年の判定に使う。
- **`prefectures`**：キー＝**公式フルネーム**（47県すべて）。値＝年→`{recognized, cleared}`（整数・件）。
  - `recognized`＝認知件数、`cleared`＝検挙件数。
  - **検挙率・全国順位・推移はアプリが表示時に算出**（JSONには入れない）。
    - 検挙率 = `cleared / recognized × 100`（recognized=0 は「-」）。
    - 全国順位 = 最新年の `recognized` 降順の**標準競争順位（1224方式）**：同数は同順位、次順位は件数分スキップ（例:3位が2県なら次は5位）。同数の表示順は都道府県コード順で安定。
  - ある県・ある年が欠損なら、その `{year}` キーを**省略**（null可）。アプリは安全にフォールバック（推移は存在年のみ、最新年欠損なら県ブロックは件数非表示）。
- **キー名は 47 都道府県フルネームで固定**（`App\Models\TouringSpot::PREFECTURE_SLUG_MAP` の値と一致）。
  URL の県名（`/bikes/area/{prefecture}`）は `shops.prefecture` フルネーム由来なので**直接一致**。アプリ側は「完全一致→前方一致」でフォールバックする。

### 差し替え時（毎年）
1. 最新年ぶんを DL・抽出し、`prefectures.{県}.{新年}` を追加、`years` に新年を足す。
2. `config/theft.php` の `data_year`（最新年）・`checked_at`（YYYY-MM）を更新。
3. デプロイ（JSONは静的・キャッシュbump不要／`config` はOPcache/設定キャッシュのリセット）。

## 4. 検証チェックリスト（配置後）
- `years` に載せた全年 × 47県が揃っているか（欠損は許容だが把握しておく）。
- 合計の桁感が警察庁の公表「街頭犯罪 オートバイ盗 全国計」と一致するか（転記ミス検出）。
- 認知 ≥ 検挙 になっているか（検挙率が100%超なら列取り違え）。
- 県名がフルネームで 47 件、余分な「全国」行が無いか。
