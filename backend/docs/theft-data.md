# バイク盗難統計データ（theft_stats.json）取得・整形手順（全国版）

`/theft` ハブが読む静的データ（**全国のオートバイ盗トレンド**）の取得元・手順・スキーマ。
年1回の差し替え（`config/theft.php` の `data_year`/`checked_at` も同時更新）を再現可能にするための記録。

> ⚠️ **スコープ縮小（案A）**：当初の「都道府県別×47県」は、警察庁/e-Stat に
> 「オートバイ盗×都道府県別×認知件数」を機械可読で綺麗に出す表が**存在しない**ため断念
> （犯罪統計のオートバイ盗は全国のみ／都道府県別は罪種が粗い／年報の都道府県別オートバイは"回復件数"で盗難数でない）。
> → **全国トレンド1枚**に縮小。都道府県別が必要なら47県警オープンデータの自前集計になる（重い・定義揺れ・不採用）。

---

## 1. 一次情報（これだけを使う。孫請け加工データ禁止）

- **警察庁『犯罪統計』 第2表「窃盗 手口別 認知・検挙件数」の「乗り物盗＞オートバイ盗」（全国）**（e-Stat）
  - 統計: 警察庁 犯罪統計（`kikan=00130`）。各年の「1〜12月犯罪統計【確定値】」CSV。
  - CSV内に `乗り物盗,オートバイ盗,<認知件数>,...,<検挙件数>,...` の全国行がある。**暫定値でなく【確定値】**を使う。
  - 全国は1ファイル1行なので軽い（都道府県別のような大量抽出は不要）。

### 年次の統計表ID（各年【確定値】・CSVダウンロード）
CSV直リンク: `https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=1`

| 年 | statInfId |
|---|---|
| 2025 | `000040410682`（認知14,552／検挙2,970＝参考実値） |
| 2024 | `000040247461` |
| 2023 | `000040141107` |
| 2022 | `000040015380` |
| 2021以前 | 各年の「1〜12月【確定値】」から同様に取得 |

## 2. 整形後スキーマ（`database/data/theft_stats.json`）★これが正本

```json
{
  "meta": {
    "source_label": "警察庁『犯罪統計』（e-Stat）",
    "source_url": "https://www.e-stat.go.jp/stat-search/files?kikan=00130",
    "unit": "オートバイ盗（全国・認知件数/検挙件数）",
    "checked_at": "2026-07"
  },
  "national": {
    "2018": { "recognized": 0, "cleared": 0 },
    "2019": { "recognized": 0, "cleared": 0 },
    "2020": { "recognized": 0, "cleared": 0 },
    "2021": { "recognized": 0, "cleared": 0 },
    "2022": { "recognized": 0, "cleared": 0 },
    "2023": { "recognized": 0, "cleared": 0 },
    "2024": { "recognized": 0, "cleared": 0 },
    "2025": { "recognized": 14552, "cleared": 2970 }
  }
}
```

### スキーマ規約（アプリ側の前提）
- **`national`**：年（文字列キー）→ `{recognized, cleared}`（整数・件）。`recognized`＝認知、`cleared`＝検挙。
- **`recognized` が 0/未設定の年は「未投入」として自動除外**（グラフ・サマリに出さない＝偽の0件トレンドを描かない）。
  各年の確定値を入れた時点でその年がトレンドに現れる。
- **検挙率・前年比・推移はアプリが表示時に算出**（JSONに入れない）：
  - 検挙率 = `cleared / recognized × 100`（recognized=0 は「-」）
  - 前年比 = `(当年 recognized − 前年 recognized) / 前年 recognized × 100`（前年が無ければ「-」）
- データが1年も無ければ `/theft` は「準備中」表示（数字を創作しない）。

### 差し替え時（毎年）
1. 最新年の【確定値】CSVからオートバイ盗（全国）の認知・検挙を取得し `national.{新年}` を実値で更新。
2. `config/theft.php` の `data_year`・`checked_at`（YYYY-MM）を更新。
3. デプロイ（JSONは静的・キャッシュbump不要／`config` はOPcache・設定キャッシュのリセット）。

---

## 3. 検証チェックリスト（配置後）
- 各年 `recognized ≥ cleared` か（検挙率が100%超なら列取り違え）。
- 桁感が警察庁公表のオートバイ盗（全国）と一致するか（転記ミス検出）。
- 未投入年（recognized=0）がトレンド・サマリに出ていないか。
