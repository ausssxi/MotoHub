# レンタル事業者を追加するときの手順

1. robots.txt を確認する（Disallow のパスは取得しない）
2. 利用規約を確認する
   - 複製・転載・再掲載の禁止条項があるか
   - 営利利用・第三者公開の禁止条項があるか
   - 会員規約しかない場合、サイト情報の再利用は縛られていない
3. どちらかに引っかかったら、その事業者は見送る
4. 問題なければフェッチャを作る
   - UA: MotoHub/1.0 (+https://motohub.jp; info@motohub.jp)
   - Accept-Language: ja
   - 1リクエスト2秒待ち・並列なし
   - 取得するのは 店舗名・住所・電話・営業時間・公式URL のみ
   - 画像・紹介文・料金・車種・在庫は取らない
5. 緯度経度は国土地理院ジオコーディングで付与
