# レンタルバイクの料金・車種情報を増やす（方針）

## 目的

/rental-bikes のコンテンツとしての価値を上げる。
店舗の場所だけでなく「いくらで、何に乗れるか」まで分かるページにする。
最終的に、事業者をまたいで料金を比べられる MotoHub 独自のページを作る。

## いまわかっていること

- 掲載事業者: レンタル819(103) / ヤマハ(81) / AJ OSAKA(22) / 二輪処(8)
- 料金の粒度
  - 全社共通: レンタル819 `/price/`、ヤマハ `/jp/bike/info/fee`、二輪処 `/price/`
  - 店舗別: AJ OSAKA `shop_bike.php?shop={id}`
- 店舗別の車種・料金ページ: 819 `/store/{id}`、AJ `shop_bike.php?shop={id}`（現 official_url）
- 4社とも、利用規約に料金・車種の転載を禁じる条項は無し（2026-09-27 確認）
- 加瀬倉庫では「参考価格＋最新は公式で確認＋公式リンク」の表示で先方の了承を得ている

## やること

### 第1段階: 公式リンク（すぐやる）
- 店舗詳細ページに公式への導線ボタンを追加
  - 819・AJ: 「この店の車種・料金を見る（公式）」→ official_url
  - ヤマハ・二輪処: 「料金表を見る（公式）」→ 事業者の料金ページ
- 事業者ごとの料金ページURLは config に持たせる
- データは取得しない

### 第2段階: 料金表を参考価格として取り込む
- 全社共通の3社（819・ヤマハ・二輪処）は、1社1枚の料金表を取得
- AJ OSAKA は店舗別（22店）
- 表示は必ず「参考価格・○年○月○日時点・最新は公式でご確認ください」＋公式リンク
- 取得前にチェックリストで再判定（料金取得を前提に）

### 第3段階: 車格別の比較ページ
- 車格（原付 / 125cc / 250cc / 400cc / 大型）ごとに、事業者の料金を並べる
- 事業者ごとに料金体系（時間・日数・保険）が違うので、比べ方は第2段階のデータを見て決める

## やらないこと

- 予約機能は作らない（予約は各社の公式へ）
- 在庫・空き状況は扱わない（リアルタイムで変わるため）
- 車両の画像は取得しない
- 「参考価格」の表記なしで料金を出さない

## 決めること（第2段階の前に）

- 料金の更新頻度（月1回？ 手動？）
- 保険・補償料金を含めるか
- 車種まで持つか、車格（クラス）単位で止めるか

## 成功条件

- 第1段階: 全店舗の詳細ページに、公式の車種・料金への導線がある
- 第2段階: 4社の料金が参考価格として表示され、取得日と公式リンクが必ず添えられている
- 第3段階: 車格を選ぶと、事業者ごとの料金を1画面で比べられる
