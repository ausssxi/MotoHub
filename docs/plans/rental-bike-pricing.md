# レンタルバイクの料金・車種情報を増やす（方針）

## 目的

/rental-bikes のコンテンツとしての価値を上げる。
店舗の場所だけでなく「いくらで、何に乗れるか」まで分かるページにする。
最終的に、事業者をまたいで料金を比べられる MotoHub 独自のページを作る。

## いまわかっていること

- 掲載事業者: レンタル819(103) / ヤマハ(81) / AJ OSAKA(22) / 二輪処(8)
- 料金の粒度
  - 全社共通: レンタル819 `/price/`、ヤマハ `/jp/bike/info/fee`、二輪処 `/price/`
  - 店舗別: AJ OSAKA `shop_bike.php?shop={id}`
- 店舗別の車種・料金ページ: 819 `/store/{id}`、AJ `shop_bike.php?shop={id}`（現 official_url）
- 4社とも、利用規約に料金・車種の転載を禁じる条項は無し（2026-09-27 確認）
- 加瀬倉庫では「参考価格＋最新は公式で確認＋公式リンク」の表示で先方の了承を得ている

## やること

### 第1段階: 公式リンク（すぐやる）
- 店舗詳細ページに公式への導線ボタンを追加
  - 819・AJ: 「この店の車種・料金を見る（公式）」→ official_url
  - ヤマハ・二輪処: 「料金表を見る（公式）」→ 事業者の料金ページ
- 事業者ごとの料金ページURLは config に持たせる
- データは取得しない

### 第2段階: 料金表を参考価格として取り込む

#### 決めたこと（2026-09-28）
- 更新頻度: **月1回・自動**
- 保険・補償料金: **取り込まない**。「保険・補償は別途（公式でご確認ください）」と注記する
- 粒度: **車格単位**（原付 / 125cc / 250cc / 400cc / 大型）。車種は持たない

#### 2-1. 調査（コードは書かない）
- 料金ページを取得する前提で、チェックリストで再判定（robots.txt・利用規約）
- 4社の料金ページの構造を確認する
  - 全社共通の3社（819・ヤマハ・二輪処）: 1社1ページ
  - AJ OSAKA: 店舗別（22店）
- 各社の料金体系を並べる（時間制か日数制か、どの時間の料金があるか）
- 各社の車格の呼び方を、MotoHub の5車格にどう当てはめるかを決める
- 比べる基準の料金を決める（例: 「1日（24時間）」を主にする）

#### 2-2. 取り込みと表示
- 料金を保存するテーブルを作る（事業者・店舗・車格・プラン・金額・取得日・取得元URL）
- 事業者ごとに料金のフェッチャを作る（UA・2秒待ち・並列なしは既存と同じ）
- 店舗詳細ページに車格別の参考価格を表示する
- 表示には必ず以下を添える
  - 「参考価格」
  - 「○年○月○日時点」
  - 「最新の料金は公式でご確認ください」＋公式リンク（第1段階のボタン）
  - 「保険・補償は別途」

#### 2-3. 月1回の自動更新
- Laravel のスケジューラで月1回、深夜に実行する
- 本番でスケジューラ（cron）が動いているか、先に確認する
- 取得に失敗したときの安全策
  - 取得できなかった・件数が0件のときは、**前回のデータを残す**（上書きしない）
  - 金額が前回から大きく変わった（例: 半分以下・倍以上）ときは、上書きせずログに残す
  - 失敗はログに残し、内田が気づける形にする
- 取得日が古くなりすぎた料金（例: 60日以上）は表示しない

### 第3段階: 車格別の比較ページ
- 車格（原付 / 125cc / 250cc / 400cc / 大型）ごとに、事業者の料金を並べる
- 事業者ごとに料金体系（時間・日数・保険）が違うので、比べ方は第2段階のデータを見て決める

## やらないこと

- 予約機能は作らない（予約は各社の公式へ）
- 在庫・空き状況は扱わない（リアルタイムで変わるため）
- 車両の画像は取得しない
- 「参考価格」の表記なしで料金を出さない

## 進捗

- 第1段階: 完了（PR `feat/rental-bike-pricing-links`）
- 第2段階: 決めること3つは決定済み（上記）。次は 2-1 調査

## 成功条件

- 第1段階: 全店舗の詳細ページに、公式の車種・料金への導線がある
- 第2段階: 4社の料金が車格別の参考価格として表示され、取得日・公式リンク・「保険は別途」が必ず添えられている。月1回自動で更新され、失敗しても古いデータが壊れない
- 第3段階: 車格を選ぶと、事業者ごとの料金を1画面で比べられる
