# HondaGO の店舗データを取り込む（調査）

## 目的

HondaGO からレンタルバイクのデータを取得する。

## いまわかっていること

- 店舗一覧のページがある
- 店舗ページは 1ページに 1件
- 地域で絞り込める
- URL: https://hondago-bikerental.jp/store/search
- 以前アクセスした際に接続拒否された（robots.txt は未確認）

## 調べること

- HondaGO のレンタル取扱店は全国で何件あるか
- 一覧ページから店舗ページのリンクが取れるか
- 取れない場合、検索結果から拾えるか

## やらないこと

- MotoHub への登録作業はしない（データ取得まで）
- 予約機能には触れない
- robots.txt で Disallow のパスは取得しない

## 成功条件

全店舗そろって成功。店舗名・住所・URL が取得できていること。

## 調査ログ

### 2026-09-24 robots.txt 確認
- `https://hondago-bikerental.jp/robots.txt` → **HTTP 404**（本文は通常の404 HTMLページ、17,712バイト、robots ディレクティブ無し）。robots.txt は**存在しない**。
- したがって `/store/` の **Disallow 記述は存在しない**。
- 接続は**成功**（以前の「接続拒否」は再発せず、HTTP/2 応答）。
- 取得は robots.txt の**1リクエストのみ**。`/store/search`・店舗ページには未アクセス。UA=`MotoHub/1.0 (+https://motohub.jp; info@motohub.jp)`。

### 2026-09-24 利用規約（/term）確認
- `https://hondago-bikerental.jp/term` → **HTTP 200**（1ページのみ取得。`/store/search`・店舗ページには未アクセス）。
- 「スクレイピング」「クローラ」「自動取得」を名指しで禁止する条項は**無し**。
- ただし **第25条 利用上の遵守事項** に取り込み・公開と衝突する制限あり:
  - 1. 提供情報を個人的利用目的の範囲を越えて使用・**複製してはならない**。複製情報を**第三者に公開・使用させてはならない**。
  - 2. 提供情報を**営利目的に使用してはならない**。
  - 3. 著作権は当社に帰属。**権利者の許諾なく使用不可**。
- 禁止事項にも「サービスによって得られた情報を**商業的に利用する行為**」「サーバー/ネットワークの機能の破壊・妨害・不正アクセス」あり。

## 結論

- **robots.txt は 404（＝クローラ向けの禁止指定は無し）。**
- **利用規約 第25条に、複製・第三者公開・営利利用の禁止がある。**
- **MotoHub の目的（取り込んで公開するプラットフォーム）と規約が正面から衝突するため、HondaGO からのデータ取得は行わない。**

→ 本調査は打ち切り。`/store/search` 以下にはアクセスしない。
