# 原付の焼き付き｜症状・原因・防ぎ方と修理費の目安【2スト・4スト】

走行中に急にエンジンが重くなって止まった。「キーッ」と金属音がして、それきり動かない——。これがエンジンの「焼き付き」だ。バイク店に話を聞くと、**持ち込まれる原付トラブルの中でいちばん多いもののひとつ**がこの焼き付きだという。

先に厳しい事実を言っておく。**一度しっかり焼き付くと、自分で直すのはほぼ無理**で、エンジンを開ける修理（あるいは載せ替え）になる。原付だと修理代が車体価格に迫ることもある。

でも逆に言えば、**焼き付きは「防ぐ」ことができる**。しかも防ぐのはほぼオイル管理だけ。この記事では、症状・原因・修理費の目安、そして二度と焼き付かせないための予防をまとめる。2ストと4ストで原因が少し違うので、そこも分ける。

## こうなったら焼き付きを疑う（症状）

焼き付きは、いきなり完全停止する場合と、じわじわ前兆が出る場合がある。

- **加速が鈍い・吹けない・パワーダウン** … 焼き付き直前のサイン。アクセルを開けても伸びない。
- **「キーッ」「ガリガリ」という金属音** … ピストンとシリンダーが擦れている音。
- **焼けるような匂い・異常な熱**
- **走行中に急にエンジンが重くなって止まる** … 引きずられるように失速して停止。
- **止まったあと、キックもセルも重い／動かない** … ピストンがロックしている状態。

軽い段階（「抱き付き」とも言う）でエンジンを止めて冷やせば、まだ助かる可能性が残ることもある。**逆に、音や失速を感じたまま走り続けると、軽傷で済むはずが完全な焼き付きになる**。

## なぜ焼き付くのか（原因）

焼き付きは「**潤滑（オイル）が足りない**」か「**熱を持ちすぎた**」かで起きる。原因のほとんどはオイルだ。

- **オイル切れ・オイル不足** … いちばん多い原因。油膜が切れて金属同士が直接擦れる。
- **オーバーヒート** … 真夏の連続高回転、登坂の酷使、冷却フィンやエアクリの詰まり。熱でピストンが膨張して固着。
- **粗悪・劣化したオイル／指定外オイル** … 油膜が保てない。
- **薄い混合気** … エアクリの破れや不調で空気が濃いと燃焼温度が上がり、熱の原因になる。

## 2ストと4ストで原因が違う

**2スト（ライブDIO・JOG初期型など）**

2ストはエンジンオイルを燃やしながら走る。多くは「分離給油」で、オイルタンクのオイルをポンプが自動で送る。だから——

- **オイルタンクが空** … オイルランプの点灯を無視して走ると一発で焼き付く。
- **オイルポンプの故障・配管の詰まり** … タンクにオイルがあっても送られていない。
- **混合給油車で混合比をミス** … オイルが少なすぎ。

2ストは「**オイルランプを絶対に無視しない**」が鉄則。

**4スト（現行Dio・トゥデイ・カブ系など）**

4ストはエンジン内のオイルで潤滑する。オイル警告ランプが無い車種が多いので、**自分で量を見ないと減っていることに気づけない**。

- **オイルの量が減っている** … 漏れ・消費・交換サボりで規定量を割る。
- **オイル交換を長期間サボった** … 劣化したオイルは潤滑性能が落ちる。
- **メタル（軸受け）の焼き付き** … オイル不足でクランクなどの軸受けが焼ける。これは修理が重い。

## 走行中に「あれ?」と思ったら（応急）

異音やパワーダウンを感じたら、**すぐに安全な場所に停めてエンジンを切る**。これが被害を最小にする唯一の手だ。

- **無理に走り続けない**。「もう少しで家だから」が完全な焼き付きを呼ぶ。
- **何度もキック・セルを繰り返さない**。ロックしているところを無理に回すと傷を広げる。
- 少し冷ませば軽い抱き付きならかかることもあるが、**ダメージは残っている**。だましだまし乗らず、早めに点検へ。

## 焼き付いてしまったら（修理費の目安・直す vs 買い替え）

完全に焼き付くと、**ピストンやシリンダーの交換（腰上オーバーホール）**、ひどければ**クランク周り（腰下）やエンジン載せ替え**になる。これは基本、自分では直せないプロの作業だ。

費用の目安（車種・店・損傷度で大きく変わる）：

- **腰上OH（ピストン・シリンダー交換）**：おおよそ2〜5万円前後
- **腰下OH・メタル焼き付き・載せ替え**：5〜10万円超になることも

原付は車体が安いぶん、**修理費が中古車体の価格に迫る・超えることがある**。だから焼き付いたら、まず店で見積もりを取って「**直す vs 買い替え**」を冷静に比べるのが大事。直すなら、なぜ焼き付いたか（オイルか熱か）を特定しないと、また同じことになる。

## 二度と焼き付かせない（防ぎ方）

ここが本題。焼き付きは直せないが、**防ぐのはほぼ全部オイル管理**で、自分でできる。

**4スト**
- オイル量を定期的にチェック（点検窓・レベルゲージ）。減っていたら早めに補充。
- 交換サイクルを守る（目安は車種マニュアル準拠。サボった分だけ焼き付きリスクが上がる）。
- → やり方は[原付のオイル交換ガイド](/blog/gentsuki-oil-change)にまとめてある。

**2スト**
- **オイルタンクの残量を定期確認。オイルランプが点いたら即補充**、無視しない。
- 純正／2スト指定のオイルを使う（安い不適合オイルで油膜が切れる）。
- オイルポンプ・配管の不調を感じたら点検。

**共通**
- 真夏の連続高回転・登坂の酷使を避ける。
- 冷却フィン・エアクリを清潔に（冷却と混合気のため）。
- **異音・パワーダウンの初期サインで止める**。これが最後の防波堤。

オイルさえ切らさなければ、焼き付きの大半は起きない。

## こんな時は店・プロへ

- すでに焼き付いて、キック・セルが回らない／重い
- 異音やパワーダウンがあるが原因がわからない
- オイルランプが点くのに原因が特定できない（ポンプ・配管の疑い）
- 修理する場合の見積もり・原因特定

エンジン内部のトラブルは素人判断が危険。少しでもおかしいと思ったら、走らせずに店へ。

## まとめ

焼き付きは原付トラブルの持ち込み件数で常に上位。**直すのは高くつくし自分では難しい。でも防ぐのは、オイルを切らさないだけ**でほとんど防げる。

「これって焼き付き? それとも別の不調?」と迷ったら、[症状診断（無料）](/trouble)で切り分けてから動くと判断が早い。

50ccの新車が買えなくなっていくこれから、今ある一台を焼き付かせずに長く乗ることの価値はますます上がる。オイルだけは、切らさないこと。
