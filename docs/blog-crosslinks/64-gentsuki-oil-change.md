# 原付のオイル交換、自分でやる？店に任せる？｜頻度・費用相場・手順まとめ

原付で一番身近で、一番大事な基本メンテナンスがオイル交換です。安く済むのに、サボると最悪エンジンが焼き付いて高額修理になる——そんな「コスパの良い予防」です。

この記事では、交換の頻度・費用の相場・自分でやる手順、そして「自分でやる／お店に任せる」のどちらが向いているかまで整理します。

## まず確認：あなたの原付は4スト？2スト？

最初に大事な分岐があります。

- **4ストローク（現在の主流）**：エンジンオイルがエンジン内に留まって潤滑するタイプ。これが一般的に言う「オイル交換」で、定期的に抜いて入れ替えます。
- **2ストローク（古い一部の車種）**：エンジンオイルは燃焼して消費されるので“交換”ではなく、専用の2ストオイルをオイルタンクに**補充**します。ただし、ミッション（ギア）オイルは別に定期交換が必要です。

以下は、主流の**4スト原付**を前提に進めます。

## 交換しないとどうなる？

オイルは走行や時間とともに汚れ・酸化し、量も減っていきます。劣化したまま乗り続けると、潤滑が効かずエンジン内部の摩耗が進み、性能や燃費が落ちます。**最悪の場合はエンジンが焼き付き、修理費が数万円〜十万円以上**に膨らむこともあります。

つまり、1,000円台のメンテをサボると、数万円の修理に化ける。これがオイル交換を「コスパの良い予防」と呼ぶ理由です。

## 交換の頻度の目安

- 目安は**走行1,000kmごと、または半年に一度**。
- **短距離のちょい乗り**が中心の人は、エンジンが温まりきらずオイルが傷みやすいので、もう少し早めが安心です。
- 新車は最初の交換を早めに行うのが基本（取扱説明書に初回の指定があります）。

確認方法は、オイルフィラーキャップのゲージを抜いて、量と色を目視するのが手軽です。最近はメーター側で交換時期を知らせてくれる車種もあります。

## 費用の相場（お店に頼む場合）

- 原付50ccで**おおむね1,000円〜**、原付二種で**1,500円〜**。
- 全体の相場は**だいたい1,000〜3,000円程度**で、使うオイルの種類と工賃でこの幅に収まります。
- 内訳は「オイル代 ＋ 工賃（無料〜2,000円ほど）」。原付はオイル量が少ないので、作業も**10分程度**で終わります。

ガソリンスタンドでも対応している店舗はありますが、すべてではないので事前確認を。専門店ほどの細かい点検は付かないこともあります。

## 自分でやる場合の手順（4スト・ざっくり）

**用意するもの**

- 指定粘度のエンジンオイル（原付は10W-30や10W-40が一般的ですが、**必ず車種の指定を確認**）
- 規定量ぶんのオイル（原付はだいたい0.5〜1L弱と少なめ。車種で違い、たとえばジャイロキャノピーは約0.5L）
- ドレンボルトを外す工具、廃油処理パック、（あれば）新しいドレンワッシャー

> 💡 [エンジンオイルの価格を比較する（楽天・Yahoo・Amazon）→](/parts/compare?keyword=バイク%20エンジンオイル)

**流れ**

1. 軽く暖機して、オイルをやわらかくする
2. ドレンボルトを外し、古いオイルを抜き切る
3. ボルトを締める（**アルミなので締めすぎ注意**）
4. 新しいオイルを規定量入れる
5. ゲージで量を確認し、エンジンをかけて漏れがないかチェック

廃油は**廃油処理パックに吸わせて、自治体のルールに従って処分**します。地面や排水に流すのは厳禁です。

## 結論：原付は「自分」と「店」どっち？

正直に言うと、**原付のオイル交換は店でも1,000円台と激安**です。DIYで浮くのは数百円程度＋廃油処理の手間がかかります。だから——

- **お店がおすすめな人**：工具がない／廃油処理が面倒／規定量や締め加減に自信がない。ついでに簡単な点検もしてもらえます。
- **自分でやるのが向く人**：いじるのが好き／整備を覚えたい／複数台ある／好きなオイルを使いたい。できるようになると、他の整備の入り口にもなります。

大事なのは「どちらでやるか」より、**ちゃんと定期的にやること**です。

## 50ccは「直して長く乗る」時代。基本メンテが効いてくる

2025年10月末で国内の50cc原付一種の新車生産は終了し、中古の50ccは値上がり傾向にあります。一台を長く乗るほど、オイル交換のような基本メンテの積み重ねが、エンジンの寿命と維持費の差になって効いてきます。
