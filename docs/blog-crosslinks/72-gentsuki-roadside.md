# バイクのレッカー、実費で払う前に｜任意保険のロードサービスで損しないために

出先でバイクが動かなくなった。パンク、バッテリー上がり、焼き付き、ガス欠——。とっさにバイク店や民間のレッカーを呼んで、数千円〜数万円を実費で払う。でも、その前に確認してほしいことがある。

整備士に話を聞くと、**「任意保険のロードサービスを知らずに、高い実費を払っている人がすごく多い」**という。知っているかどうかだけで、数万円の差がつくことがある。

## 任意保険には「ロードサービス」が付いていることが多い

多くのバイクの任意保険には、**ロードサービス（ロードアシスト）**が付帯している。レッカー牽引や現場での応急対応を、無料または割安で受けられる仕組みだ。

それなのに使われないのは、単純に**「付いていることを知らない」**から。いざ止まると焦って、目の前のバイク店や、検索で最初に出てきたレッカー業者に電話してしまう。

## 自賠責だけだと付かない

ここを誤解している人が多い。

- **自賠責保険（強制）** … 対人の賠償だけ。**ロードサービスは付かない**。
- **任意保険（任意）** … ロードサービスが付帯していることが多い。

原付は「自賠責だけ」で乗っている人も多い。その場合、保険からのレッカーは期待できない。まず**自分が任意保険に入っているか、入っているならロードサービスが付いているか**を確認するのが出発点。

**原付で注意：ファミリーバイク特約**
原付を、車の保険の「ファミリーバイク特約」でカバーしている人も多い。この特約は賠償が中心で、**ロードサービスが付かない・限定的なことがある**。その場合はJAFや別途のバイク保険が選択肢になる。

## ロードサービスで何ができる?（一般的な内容）

保険会社によって条件は違うが、だいたいこんな内容：

- **レッカー牽引** … 故障現場から修理工場まで、**一定距離まで無料**（距離の上限は保険による）。
- **現場での応急対応** … バッテリー上がりのジャンプ、パンクの応急、キー閉じ込みの開錠、ガス欠の燃料配達（燃料代は別）など。
- **回数・距離の条件** … 年間の利用回数や無料距離に上限があることが多い。

「無料レッカーは何kmまで?」は保険ごとに違うので、ここは必ず自分の契約で確認しておく。

## JAFという選択肢もある

JAF会員なら、**バイク（原付含む）もロードサービスの対象**。会員本人にかかるサービスなので、車・バイクを問わず使える。任意保険のロードサービスとJAF、両方持っている人もいる。バイク保険にロードサービスが付いていないなら、JAFを検討する価値がある。

## 動かなくなったら、確認する順番

止まってから慌てないために、**この順番**を覚えておく。

1. **加入している任意保険のロードサービスに電話**（無料・割安なことが多い）
2. **JAF**（会員なら）
3. それでも該当が無ければ、バイク店・民間のレッカー（実費）

ポイントは、**いきなり3に飛ばないこと**。1と2を持っているのに使わないと、払わなくていいお金を払うことになる。

## 今すぐ、自分の保険を確認しておこう

トラブルは突然来る。**動かなくなってからでは調べる余裕がない**。今のうちに：

- 保険証券か保険会社のアプリで「**ロードサービスの付帯があるか**」を確認
- 「**レッカー無料距離**」と「**連絡先**」をチェック
- ロードサービスの**電話番号をスマホに登録**しておく

任意保険に入っていない・ロードサービスが付いていないなら、この機会に検討を。原付でも、トラブル一回のレッカー代で年会費が見合うこともある。

## まとめ

バイクが動かなくなった時、**知っているかどうかだけで数万円の差**がつく。自賠責だけでは付かない、任意保険には付いていることが多い、JAFという手もある——。まずは自分の保険を確認して、連絡先をスマホに入れておく。それだけで、いざという時に損をしない。

「そもそもこれは何の不調?」と原因が知りたいときは、[症状診断（無料）](/trouble)で切り分けてみてほしい。
