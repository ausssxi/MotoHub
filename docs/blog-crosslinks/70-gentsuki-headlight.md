# 原付のヘッドライト交換は自分でできる｜費用・手順・車種別の注意（ライブDIOは3ネジ）

夜道でヘッドライトがつかない、暗い、片方だけ消えた——。すぐバイク屋に持ち込みたくなるけど、ちょっと待ってほしい。原付のヘッドライトバルブ交換は、整備の中でもいちばん簡単な作業のひとつ。実際、整備士に聞くと「一度やれば、二度目からは誰でもできる」と口を揃える。

この記事では、店に工賃を払う前に自分で交換するための手順を、**ライブDIOを例に**説明する。費用の目安、車種ごとの違い、LED化の注意、そして「これは店に任せたほうがいい」ケースまでまとめた。

## まず確認：本当に「球切れ」か？

替える前に、原因が本当にバルブ切れか軽く切り分けておく。原付のヘッドライトが点かない原因はいくつかある。

- **球切れ** … いちばん多い。フィラメントが切れている、ガラス内が黒く焼けている。
- **接触不良・配線** … コネクタが緩んでいる、端子が腐食している。
- **ヒューズ切れ** … ほかの電装と一緒に消えていればこれを疑う。
- **スイッチ/Hi-Lo切替の不良** … ロービームだけ、ハイだけ点かない場合。
- **回転で明るさが変わる** … 古い2スト原付はヘッドライトが「交流点灯」のことが多く、アイドリングで暗く、回すと明るくなるのは正常。まったく点かないのとは別問題。

エンジンをかけて、Hi/Loを切り替えて、片方でも点くか確認する。完全に無反応ならヒューズや配線、フィラメントが切れていれば球交換、と見当をつけてから作業に入ると早い。

## 店に頼むといくら？自分だと？

ヘッドライトバルブそのものは、ハロゲン球なら数百円〜1,500円ほど。LEDでも数千円程度から手に入る。

これを店に頼むと、部品代に**工賃**が乗る。工賃は店によるが、1,000〜3,000円ほどを見ておくといい。要はカウルを外す手間賃で、「部品より工賃のほうが高い」状態になりがちだ。

自分でやれば、かかるのはバルブ代だけ。作業も慣れれば10分かからない。「どこで替えればいい?」と検索している人が多いけど、答えは実は「自分の手元」。

## 用意するもの

- 交換用バルブ（**規格は車種で違う**。PH7・PH8・T19Lなどがあるので、外した球の刻印か、車種の適合表で確認してから買う)
- プラスドライバー（カウルのネジ用)
- 軍手（ハロゲン球はガラスに素手で触らない。指の脂が熱で焼けて寿命が縮む)

## 交換手順（ライブDIOを例に）

ライブDIOはフロントカウルがネジ3本で留まっている、いちばん簡単な部類。

1. **フロントカウルのネジを外す**。ライブDIOなら3本。車種によってはメーターまわりや、キャップ（ネジ隠し)の下に隠れていることがあるので、無理に引っ張らず全部のネジを探す。
2. **カウルをそっと外す**。爪（ツメ)で噛み合っている部分があるので、ネジを全部外したら手前に引いて爪を抜く。割らないように、力任せにしない。
3. **バルブのコネクタを抜く**。ヘッドライト裏の配線カプラを引き抜く。
4. **バルブの固定を外す**。針金状のクリップ（バネ)を押して外すか、口金を回して外す。タイプは車種による。
5. **新しいバルブを入れる**。ガラスは素手で触らない。クリップ/口金でしっかり固定。
6. **コネクタを挿す → 点灯確認 → カウルを戻す**。先に点くか確認してからカウルを閉じると、やり直しがラク。

ポイントは「ネジを全部外す」「爪を割らない」「球を素手で触らない」の3つだけ。

## 車種別のちょっとした違い

- **DIO系（ライブDIO/スーパーDIO/トゥデイ/タクト)** … フロントカウルのネジ数本で素直にアクセスできる部類。
- **ビーノ/ジョルノ/JOG** … カウルの分割やレンズユニットの留め方が違うことがある。ネジの位置をよく見てから。
- **共通** … 隠しネジ・キャップの下のネジを見落とすと外れない。焦らず全部探すのが一番の近道。

外し方が不安なら、自分の車種名＋「カウル 外し方」で画像を見ておくと一発でわかる。

## LEDに替えたい人へ（交流点灯の注意）

「ついでにLEDにして明るくしたい」人は要注意。古い2スト原付（ライブDIOなど)は、ヘッドライトがバッテリー（直流)ではなく**交流（エンジンの発電直結)**で点いていることが多い。この場合、普通の直流用LEDをそのまま入れても、点かない・ちらつく・回転で明るさが変わる、ということが起きる。

LED化するなら**交流対応のLEDバルブ**を選ぶか、整流（直流化)が必要になる場合がある。まずは自分の車種が直流点灯か交流点灯かを確認してから選ぶこと。とりあえず「今切れたのを直したい」だけなら、純正と同じハロゲン球を入れるのが確実で安い。

## 交換時期の目安

ヘッドライトは「切れてから替える」で基本OKだけど、

- 以前より暗くなった、黄ばんできた
- 片方が切れた（もう片方も近いうちに切れることが多い)

こんな時は早めに替えておくと、夜道で突然真っ暗、を防げる。車検のない原付こそ、自分でこまめに見ておきたい部分だ。

## こんな時は店・プロへ

次のような場合は無理せず店に相談する。

- 配線が焦げている、被覆が溶けている、コゲ臭い
- ヒューズを替えてもすぐまた飛ぶ
- LED化で整流器やレギュレータをいじる必要がある
- カウルを外したが、配線やカプラの状態がよくわからない

電装のトラブルは、原因を間違えると火が出ることもある。少しでも「おかしい」と思ったら、プロに見てもらうのが結局いちばん安い。
